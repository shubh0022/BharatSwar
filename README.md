## 🌍 Vision

BharatSwar is a next-generation music ecosystem designed to preserve, discover, and celebrate Indian music across every language, culture, region, and era.

From ancient classical ragas and folk traditions to modern Bollywood, indie artists, devotional music, podcasts, and AI-generated playlists, BharatSwar aims to become the digital home of Indian music.

# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/yourusername/bharatswar.git

cd bharatswar
```

## Install

```bash
npm install
```

## Environment Variables

```env
DATABASE_URL=
REDIS_URL=

OPENAI_API_KEY=
FIREBASE_API_KEY=

MUSICBRAINZ_API=
LASTFM_API_KEY=
DEEZER_API=
```

## Run Development

```bash
npm run dev
```
